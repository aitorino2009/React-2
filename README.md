# React-2: Programación Funcional y Condicionales (APOF)

Proyecto con la resolución completa de los ejercicios del dossier de React y JavaScript (Unidades 2 y 3).

---

## Estructura de archivos

- `RESPUESTAS_TEORIA.md`: Respuestas a los ejercicios teóricos 2.3.2 (función pura) y 2.4.1 (lenguajes funcionales y ventajas frente al paradigma imperativo).
- `src/exercici1.jsx` & `src/Ejercicio2.jsx`: Ejercicios 3.1 y 3.2 (Comprobador de notas con operador ternario).
- `src/Exercici3.jsx`: Ejercicio 3.3 (Programa de admisión por edad).
- `src/exercic4.jsx`: Ejercicio 3.4 (Condicional múltiple de 3 tramos de edad).
- `src/exercici5.jsx`: Ejercicio 3.5 (Ampliación con edad mayor de 100 años).
- `src/exercici6.jsx`: Ejercicio 3.6 (Comparador de números con caso de igualdad según pseudocódigo).
- `src/exercici7.jsx`: Ejercicio 3.7 con Nota (Cálculo de tarifas según la edad).
- `src/App.jsx`: Componente principal que visualiza de forma ordenada todos los ejercicios.

---

## Instrucciones de uso

1. Instalar dependencias:
   ```bash
   npm install
   ```

2. Iniciar el servidor de desarrollo:
   ```bash
   npm run dev
   ```

3. Compilar para producción:
   ```bash
   npm run build
   ```
